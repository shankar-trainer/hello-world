Here is a complete, minimal example of how to integrate OpenAI with a Spring Boot application using Spring AI.
Spring AI provides a high-level abstraction layer using the ChatClient API. This allows you to swap or configure different AI models seamlessly without changing your core application logic.

1. Project Dependencies (pom.xml)

Add the official Spring Boot starter for OpenAI to your Maven configuration. This includes the required auto-configuration packages.
xml
<dependencies>
    <!-- Web starter to create a REST API endpoint -->
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>

    <!-- Spring AI OpenAI Starter -->
    <dependency>
        <groupId>org.springframework.ai</groupId>
        <artifactId>spring-ai-openai-spring-boot-starter</artifactId>
    </dependency>
</dependencies>
Use code with caution.

2. Configuration (application.properties)

Configure your OpenAI credentials and model choices. For security best practices, fetch your private token from an environment variable rather than hardcoding it.
properties
# Authentication Key from platform.openai.com
spring.ai.openai.api-key=${OPENAI_API_KEY}

# Optional Configuration Customization
spring.ai.openai.chat.options.model=gpt-4o
spring.ai.openai.chat.options.temperature=0.7

Use code with caution.
Key Parameters Explained:
• model: Determines the distinct LLM intelligence engine powering the requests (e.g., gpt-4o, gpt-5-mini).
• temperature: Regulates response randomness. Values near 0.0 provide stable, deterministic facts, while values approaching 1.0 drive creative variability.

3. The REST Controller Implementation

Use Spring AI's modern ChatClient.Builder to safely instantiate thread-safe request processors.
java
package com.example.ai.controller;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/ai")
public class ChatController {

    private final ChatClient chatClient;

    // The ChatClient.Builder is auto-configured and injected automatically by Spring Boot
    public ChatController(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    @GetMapping("/chat")
    public String generateResponse(@RequestParam(value = "message") String message) {
        return this.chatClient
                .prompt()
                .user(message)
                .call()
                .content();
    }
}
Use code with caution.

How the Code Works Step-by-Step

1. Auto-Configuration Activation: When the app starts, Spring Boot detects the spring-ai-openai-spring-boot-starter dependency. It automatically reads your spring.ai.openai.api-key and exposes a pre-configured ChatClient.Builder bean into the context.
2. Constructor Injection: The ChatController requests this builder, calling .build() to initialize an immutable, reusable ChatClient instance.
3. Fluent API Chain:
	• .prompt(): Initializes a new request context window.
	• .user(message): Passes the end-user's question dynamically into the prompt engine.
	• .call(): Synchronously dispatches the payload via secure HTTP client wrapper to OpenAI's servers.
	• .content(): Extracts the raw structural textual answer out of the payload response, discarding unnecessary metadata tokens.

How to Test

1. Set your environment variable: export OPENAI_API_KEY="your-actual-api-key"
2. Start the Spring Boot application.
3. Open your browser or execute a curl request:bash
curl "http://localhost:8080/api/ai/chat?message=Why is the sky blue?"
