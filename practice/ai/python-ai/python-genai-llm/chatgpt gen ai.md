# 1. Simple GenAI example using Python

Imagine you want Python to generate an email using AI.

Beginner example### Step 1: Install the OpenAI library

Open your terminal and run:

bash

```bash
pip install openai
```

### Step 2: Write Python code

You need an OpenAI API key from the OpenAI developer platform.

python

```python

from openai import OpenAI

# Create AI client
client = OpenAI(
    api_key="YOUR_API_KEY"
)

# Give instructions to AI
response = client.responses.create(
    model="gpt-4.1",
    input="Write a professional leave request email for 2 days."
)

# Display AI-generated output
print(response.output_text)
```

### Step 3: Expected output

text

```text
Subject: Leave Request

Dear Manager,

I would like to request leave
for two days due to personal reasons.

Kindly approve my leave request.

Thank you.
```

This is a simple Generative AI application because Python sends instructions to an AI model, and the model generates new text.
