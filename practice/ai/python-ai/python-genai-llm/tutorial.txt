python use ollama model on cloud not local example

To run models on Ollama Cloud instead of your local machine using Python, you must direct your requests to the Ollama Cloud API endpoint (https://ollama.com) and authenticate using an OLLAMA_API_KEY.
You can implement this using the official ollama Python library or standard OpenAI-compatible clients.

Method 1: Using the Official Ollama Python SDK

The official ollama library allows you to initialize a Client targeting the cloud host.
First, install the library:

bash
pip install ollama

Use code with caution.
Set your API key in your environment terminal:
bash
export OLLAMA_API_KEY="your_ollama_cloud_api_key_here"
export OLLAMA_API_KEY="83e8e6bea3294c04b0cdffaa5f3d49cc.nfiNsZs4z_0t_MQlO9bTceBY"

in powershell 

$env:OLLAMA_API_KEY = "83e8e6bea3294c04b0cdffaa5f3d49cc.nfiNsZs4z_0t_MQlO9bTceBY"


Use code with caution.
Run the following Python script:
python
import os
from ollama import Client

# Initialize the client pointing to Ollama Cloud
client = Client(
    host="https://ollama.com",
    headers={"Authorization": f"Bearer {os.environ.get('OLLAMA_API_KEY')}"}
)

# Call a cloud-designated model (e.g., qwen3-coder:480b-cloud)
response = client.chat(
    model="qwen3-coder:480b-cloud",
    messages=[
        {
            "role": "user",
            "content": "Write a python function to check if a number is prime.",
        }
    ]
)

print(response["message"]["content"])

Use code with caution.

Method 2: Using the OpenAI Python SDK (Recommended)

Because Ollama Cloud features an OpenAI-compatible API, you can bypass the local Ollama server completely and make direct stateless cloud requests.
First, install the OpenAI client:
bash
pip install openai

Use code with caution.
Run the following Python script:
python

import os
from openai import OpenAI

# Configure the client to hit the Ollama Cloud v1 endpoint
client = OpenAI(
    base_url="https://ollama.com/v1",
    api_key=os.environ.get("OLLAMA_API_KEY")
)

# Call the cloud model
completion = client.chat.completions.create(
    model="qwen3-coder:480b-cloud", 
    messages=[
        {"role": "user", "content": "Explain quantum computing in one sentence."}
    ]
)

print(completion.choices[0].message.content)
Use code with caution.

Key Differences When Moving to the Cloud

• Authentication: Local requests require no keys, but cloud endpoints strictly require a valid OLLAMA_API_KEY passed as a bearer token.
• Model Naming: Cloud-hosted models use a specific suffix syntax (e.g., qwen3-coder:480b-cloud, deepseek-v3.1:671b-cloud).
• Stateless Actions: You cannot perform server management commands like creating or deleting custom models programmatically via the cloud endpoints.

ollama uses open ai

You can use the OpenAI Python or JavaScript SDK with Ollama by pointing the client's baseURL to your local Ollama server (http://localhost:11434/v1).

How to Configure

• Base URL: Set it to http://localhost:11434/v1.
• API Key: Use a dummy string like "ollama" (it is required by the SDK but not verified by Ollama locally).
• Model Name: Pass the name of the model you pulled locally in Ollama (for example, llama3.2 or gpt-oss).

Python Code Example

python
from openai import OpenAI

client = OpenAI(
    base_url='http://localhost:11434/v1',
    api_key='ollama',  # required, but unused
)

response = client.chat.completions.create(
    model='llama3.2',
    messages=[{'role': 'user', 'content': 'Why is the sky blue?'}],
)

print(response.choices[0].message.content)
Use code with caution.

JavaScript / Node.js Code Example

javascript
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:11434/v1',
  apiKey: 'ollama', // required, but unused
});

const completion = await openai.chat.completions.create({
  model: 'llama3.2',
  messages: [{ role: 'user', content: 'Why is the sky blue?' }],
});

console.log(completion.choices[0].message.content);
Use code with caution.

Supported Endpoints

Ollama's OpenAI-compatible layer supports:
• /v1/chat/completions (supports streaming, tools, and JSON mode)
• /v1/completions
• /v1/models and /v1/models/{model}
• /v1/embeddings
For more details, check the Ollama OpenAI Compatibility Documentation.
