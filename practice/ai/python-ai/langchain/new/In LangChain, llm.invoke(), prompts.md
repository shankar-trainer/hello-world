In LangChain, llm.invoke(), prompts, and topics represent distinct layers of how you construct inputs and call a language model.

1. What is a Prompt / Prompt Template?

• What it is: The text, question, or structured set of messages you send to the language model.
• PromptTemplate / ChatPromptTemplate: Instead of hardcoding static strings, LangChain uses prompt classes with dynamic placeholders (like {topic} or {audience}) so you can reuse them safely.
• Example:python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template(
    'Explain {topic} in simple terms.'
)
Use code with caution.

### 2. What is the "Topic"?
* **What it is:** Just a **variable/data value** (e.g., `"vector databases"`, `"quantum computing"`, `"dog"`) that you plug into your prompt template's placeholder. 
* It is not a LangChain method or core object on its own; it is simply part of the dictionary of variables (`{"topic": "quantum computing"}`) passed into a prompt or a chain.

### 3. What is `llm.invoke()`?
* **What it is:** The standard execution method on a Runnable object (such as an LLM, Chat Model, or LCEL chain) that sends the payload to the model and **waits for the complete response** before returning.
* **How it interacts with prompts:** You can either format the prompt first and pass it to `llm.invoke(prompt)`, or—more commonly in modern LangChain—use the pipe operator (`|`) via LangChain Expression Language (LCEL) to bind them together:

---

### How They Work Together (The Flow)

1. **Define the Prompt Template** (with a variable like `{topic}`).
2. **Combine via LCEL** (`chain = prompt | llm`).
3. **Call `.invoke()`** passing in the dictionary containing the actual value for `{topic}`:

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# 1. Create a prompt template with a 'topic' variable
prompt = ChatPromptTemplate.from_template('Tell me a short fact about {topic}.')

# 2. Initialize the model
llm = ChatOpenAI(model='gpt-4o-mini')

# 3. Create a chain using the pipe operator
chain = prompt | llm

# 4. Invoke the chain, supplying the 'topic' value
response = chain.invoke({'topic': 'black holes'})
print(response.content)

Here is how you can stream the response token-by-token and use output parsers to format the data into a clean string or structured JSON.

1. Streaming Responses with .stream()

Instead of waiting for the entire text to generate (which can take several seconds), .stream() yields chunks of the response as they are generated by the AI. This is ideal for building snappy user interfaces.
python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("Tell me a detailed fact about {topic}.")
llm = ChatOpenAI(model="gpt-4o-mini")
chain = prompt | llm

# Use .stream() instead of .invoke()
for chunk in chain.stream({"topic": "supernovas"}):
    # Print each token chunk immediately without a newline
    print(chunk.content, end="", flush=True)
Use code with caution.

2. Cleaning Text with a String Output Parser

By default, calling a chat model returns an AIMessage object filled with metadata. If you just want the plain text, use StrOutputParser. It automatically extracts the text string.
python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("Explain {topic} in one sentence.")
llm = ChatOpenAI(model="gpt-4o-mini")

# Add StrOutputParser to the end of your chain
chain = prompt | llm | StrOutputParser()

# Returns a direct string instead of an AIMessage object
response = chain.invoke({"topic": "photosynthesis"})
print(response)  # Output: "Photosynthesis is the process..."
Use code with caution.

3. Extracting Structured Data with Pydantic

If you need the LLM to return data in a reliable, machine-readable format (like a JSON object to save into a database), use with_structured_output() paired with a Pydantic schema.
python
from pydantic import BaseModel, Field
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# 1. Define the data structure you want
class ScientificConcept(BaseModel):
    name: str = Field(description="The name of the concept")
    difficulty: str = Field(description="The difficulty to understand (Easy, Medium, Hard)")
    one_sentence_summary: str = Field(description="A brief explanation of the concept")

# 2. Set up the prompt and model
prompt = ChatPromptTemplate.from_template("Analyze the following topic: {topic}")
llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# 3. Force the model to output structured JSON matching your schema
structured_llm = llm.with_structured_output(ScientificConcept)

# 4. Chain and execute
chain = prompt | structured_llm
result = chain.invoke({"topic": "quantum entanglement"})

# This returns a fully typed Python object
print(result.name)
print(result.difficulty)
print(result.one_sentence_summary)
Use code with caution.

Here is how you can set up automatic fallbacks to handle model errors, followed by how to connect a vector database to build a complete Retrieval-Augmented Generation (RAG) system.

1. Robust Chains: Error Handling & Fallbacks

Language models can sometimes fail due to API rate limits, server downtime, or strict formatting failures (like failing to output valid JSON). LangChain lets you attach a .with_fallbacks() mechanism so that if your primary model fails, a backup takes over seamlessly.
python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic

prompt = ChatPromptTemplate.from_template("Explain {topic} in one sentence.")

# Define your primary choice and your backup alternative
primary_model = ChatOpenAI(model="gpt-4o-mini", max_retries=1)
backup_model = ChatAnthropic(model="claude-3-5-haiku-latest")

# Attach the fallback behavior to your primary model
robust_model = primary_model.with_fallbacks([backup_model])

# Build the chain normally
chain = prompt | robust_model

# If OpenAI fails or times out, LangChain will automatically try Claude
response = chain.invoke({"topic": "API rate limits"})
print(response.content)
Use code with caution.

2. Knowledge-Infused Chains: Building a RAG Pipeline

To stop an LLM from hallucinating, you can feed it relevant documents from a vector database before it answers.
A RAG pipeline uses a retriever to fetch matching content based on the user's question, formats those documents into a context block inside your prompt, and then hands it off to the model.
python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_core.vectorstores import InMemoryVectorStore

# 1. Setup a dummy vector store with your private data
vector_store = InMemoryVectorStore(OpenAIEmbeddings())
vector_store.add_texts([
    "Project Alpha is our internal code name for the 2027 quantum encryption rollout.",
    "Project Beta is our legacy system slated for decommissioning in Q4."
])

# 2. Convert the vector store into a LangChain Retriever
retriever = vector_store.as_retriever(search_kwargs={"k": 1})

# 3. Create a prompt template that accepts context and a question
rag_prompt = ChatPromptTemplate.from_template("""
Answer the question based only on the following context:
{context}

Question: {question}
""")

llm = ChatOpenAI(model="gpt-4o-mini")

# 4. Construct the LCEL RAG Chain
# RunnablePassthrough allows the user's raw question to skip ahead directly into the {question} slot
rag_chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | rag_prompt
    | llm
    | StrOutputParser()
)

# 5. Invoke the chain with just your query
response = rag_chain.invoke("What is Project Alpha?")
print(response) 
# Output: "Project Alpha is the internal code name for the 2027 quantum encryption rollout."
Use code with caution.
