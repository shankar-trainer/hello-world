The error occurs because in newer versions of LangChain, LLMChain is no longer available in the same way as older versions. LangChain has moved toward using LCEL (LangChain Expression Language) with the pipe (|) operator.

You can fix this in two ways.

1. Recommended: Use LCEL (new approach)
You don't need LLMChain at all.


python
from langchain_ollama import OllamaLLM
from langchain_core.prompts import PromptTemplate

llm = OllamaLLM(
    model="qwen3.5:2b",
    temperature=0.1
)

prompt = PromptTemplate(
    input_variables=["topic"],
    template="Tell me about {topic}"
)

# Create chain
chain = prompt | llm

# Invoke chain
response = chain.invoke({"topic": "Begusarai"})

print(response)

4. Understand how LCEL works
PromptTemplate

Formats your input

OllamaLLM

Generates the response

chain.invoke()

Returns the generated output

My recommendation: Learn LCEL (prompt | llm) because it is the modern approach and is easier to combine with retrievers, output parsers, and other LangChain components.
