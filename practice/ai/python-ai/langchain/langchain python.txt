Option 1: The LangChain Approach (Modular & Scalable)
LangChain uses a standard interface called LCEL (LangChain Expression Language) to chain models, prompt templates, and outputs together.
YouTube +1

1. Install dependencies
bash

pip install langchain-core langchain-openai python-dotenv

Use code with caution.
2. The Code
Create a file named app_langchain.py:
python

import os
from dotenv import load_dotenv
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# Load environment variables (Make sure you have OPENAI_API_KEY in a .env file)
load_dotenv()

def generate_ai_response(topic: str) -> str:
    # 1. Initialize the Language Model
    model = ChatOpenAI(model="gpt-4o-mini", temperature=0.7)
    
    # 2. Define a reusable prompt template
    prompt = ChatPromptTemplate.from_messages([
        ("system", "You are a witty, brilliant AI assistant. Explain topics concisely."),
        ("user", "Explain the concept of {topic} in three bullet points.")
    ])
    
    # 3. Create a clean pipeline (Chain) using the "|" operator
    # This pipes: Prompt -> LLM -> Raw text extraction
    chain = prompt | model | StrOutputParser()
    
    # 4. Execute the chain
    response = chain.invoke({"topic": topic})
    return response

if __name__ == "__main__":
    result = generate_ai_response("Quantum Computing")
    print(result)

Option 2: The Native SDK Approach (No Framework)
If you want to avoid third-party frameworks and interact directly with an AI provider (like OpenAI), you can use their official client library.
1. Install dependencies
bash

pip install openai python-dotenv

Use code with caution.
2. The Code
Create a file named app_native.py:
python

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

def generate_native_response(topic: str) -> str:
    # Initialize the official OpenAI client
    client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))
    
    # Direct API request structure
    completion = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": "You are a witty, brilliant AI assistant. Explain topics concisely."},
            {"role": "user", "content": f"Explain the concept of {topic} in three bullet points."}
        ],
        temperature=0.7
    )
    
    # Extract data manually from the response object
    return completion.choices[0].message.content

if __name__ == "__main__":
    result = generate_native_response("Quantum Computing")
    print(result)
