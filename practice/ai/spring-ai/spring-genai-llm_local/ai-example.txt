spring boot 4.x ai simple example with open ai

Integrating Spring Boot 4.x and Spring AI 2.x allows you to leverage Java 17+ (with optimized support for Java 25), Spring Framework 7.0, and a highly optimized, fluent AI ChatClient architecture.
A minimal, production-ready "Hello World" example utilizing Spring Boot 4.1 and the Spring AI 2.0+ OpenAI starter follows.

1. Build Configuration (pom.xml)

Spring Boot 4.x aligns with Jakarta EE 11 and utilizes the unified Spring AI Bill of Materials (BOM) to manage versions.
xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://apache.org" 
         xmlns:xsi="http://w3.org"
         xsi:schemaLocation="http://apache.org https://apache.org">
    <modelVersion>4.0.0</modelVersion>
    
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>4.1.0</version> <!-- Active Spring Boot 4.x Release -->
        <relativePath/>
    </parent>

    <groupId>com.example</groupId>
    <artifactId>spring-boot-4-ai-demo</artifactId>
    <version>0.0.1-SNAPSHOT</version>

    <properties>
        <java.version>17</java.version> <!-- Supports up to Java 25 natively -->
    </properties>

    <dependencies>
        <!-- Standard Spring Boot Web Starter -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- Spring AI OpenAI Starter -->
        <dependency>
            <groupId>org.springframework.ai</groupId>
            <artifactId>spring-ai-openai-starter</artifactId>
        </dependency>
    </dependencies>

    <dependencyManagement>
        <dependencies>
            <!-- Managed BOM for Spring AI 2.x Ecosystem -->
            <dependency>
                <groupId>org.springframework.ai</groupId>
                <artifactId>spring-ai-bom</artifactId>
                <version>2.0.0</version> 
                <type>pom</type>
                <scope>import</scope>
            </dependency>
        </dependencies>
    </dependencyManagement>
</project>
Use code with caution.

2. Configure Your OpenAI API Key

Expose your OpenAI API credentials as an environment variable. The Spring AI auto-configuration wrapper will pick this up implicitly:
bash
export OPENAI_API_KEY="your-actual-api-key-here"
Use code with caution.
In your src/main/resources/application.properties file, specify your preferred configuration options:
properties
# Target OpenAI model optimization
spring.ai.openai.chat.options.model=gpt-4o
spring.ai.openai.chat.options.temperature=0.7
Use code with caution.

3. Implement the REST Controller

Spring AI 2.x shifts focus toward using the fluent, thread-safe ChatClient.Builder to manage local LLM setups.
java
package com.example.demo;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class AIController {

    private final ChatClient chatClient;

    // The builder is auto-configured and injected securely via the starter dependency
    public AIController(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder
                .defaultSystem("You are a helpful software engineering assistant.")
                .build();
    }

    @GetMapping("/api/chat")
    public String askAi(@RequestParam(value = "message", defaultValue = "Explain Virtual Threads in Spring Boot 4") String message) {
        return this.chatClient.prompt()
                .user(message)
                .call()
                .content();
    }
}
Use code with caution.

4. Run and Validate

Boot up the application by executing your standard entry point class (@SpringBootApplication). Once running, execute a standard browser lookup or run a quick terminal command to fetch a response:
bash
curl "http://localhost:8080/api/chat?message=Why+use+Spring+AI?"
Use code with caution.

Why this setup is optimal for Boot 4:

• Fluent API Efficiency: The chain syntax .prompt().user().call().content() allows you to change internal implementation details effortlessly. Swapping OpenAI for Anthropic or Ollama requires only a dependency switch—your controller logic remains intact.
• Optimized Model Execution: This design interfaces cleanly with modern Spring 7 internals, utilizing lighter footprint execution contexts and faster Jackson object serializations out of the box.

Implementation Components
Understanding Prompts
Prompts are the inputs provided to the AI model that guide its responses. They can be:

Simple questions
Complex instructions
Contextual information
Spring AI allows prompts to be represented as straightforward strings or through structured templates. The quality of your prompt significantly impacts the relevance and accuracy of the AI’s response.

Service Layer Implementation
This layer facilitates communication with the AI provider through Spring AI’s ChatModel class, specifically using OpenAiChatModel for OpenAPI integration. Key responsibilities include:

Receiving and processing user queries
Converting queries into appropriate prompt formats
Submitting prompts to the AI model
Processing AI responses into usable formats (text, objects, or structured data)
Potentially supporting multiple AI providers through a façade pattern
@Service
@Slf4j
public class AIQueryServiceImpl implements AIQueryService {

    private final ChatModel chatModel;

    public AIQueryServiceImpl(ChatModel chatModel) {
        this.chatModel = chatModel;
    }

    public String query(String query) {
        PromptTemplate userPromptTemplate = new PromptTemplate("{query}");
        Message userMessage = userPromptTemplate.createMessage(Map.of("query", query));

        Prompt prompt = new Prompt(userMessage);
        Generation generation = chatModel.call(prompt).getResult();
        return generation.getOutput().getText();
    }
}
Controller Layer Functions
This layer:

Accepts incoming user requests
Forwards queries to the service layer
Returns formatted AI responses to users
@RestController
@RequestMapping("/ai")
@Slf4j
public class AIQueryController {

    private final AIQueryService aiQueryService;

    public AIQueryController(AIQueryService aiQueryService) {
        this.aiQueryService = aiQueryService;
    }

    @GetMapping("/query")
    public String chat(@RequestParam(name = "query") String query) {
        return aiQueryService.query(query);
    }
}
