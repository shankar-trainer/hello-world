In the example provided, two core Spring AI APIs are utilized to manage the interaction with the local LLM:

1. The Fluid API: ChatClient

The primary API used to construct and execute the prompt is ChatClient.
Spring AI provides this high-level, fluent interface (similar to Spring's RestClient or WebClient) to simplify how you interact with AI models. In the code, the API calls are chained together like this:
• chatClient.prompt(): Starts the creation of a new AI request context.
• .user(prompt): Specifies the input text or message originating from the end-user.
• .call(): Sends the compiled request synchronously to the Ollama endpoint.
• .content(): A convenience method that extracts the raw text string directly from the response payload, bypassing the underlying metadata wrapper.

2. The Low-Level SPI: OllamaChatModel (Driven via ChatClient.Builder)

Behind the scenes, the OllamaChatModel class handles the low-level communication.
While you do not see OllamaChatModel explicitly written in the controller code, it is the actual infrastructure implementation injected into the ChatClient.Builder behind the scenes by the starter dependency (spring-ai-starter-model-ollama).
• The builder pattern decouples your business logic from the specific AI provider.
• If you swapped Ollama out for OpenAI or Anthropic in your dependencies, the ChatClient code snippet in the controller would remain exactly the same.

1. Using the Lower-Level OllamaChatModel Directly

If you need direct access to the underlying engine to pass specialized, model-specific configurations (OllamaOptions), you can inject OllamaChatModel instead of the builder.
Here is how to write the controller using the direct model API:
java
package com.example.ai.controller;

import org.springframework.ai.chat.messages.UserMessage;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.ai.ollama.OllamaChatModel;
import org.springframework.ai.ollama.api.OllamaOptions;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class DirectOllamaController {

    // Inject the model directly instead of ChatClient.Builder
    private final OllamaChatModel chatModel;

    public DirectOllamaController(OllamaChatModel chatModel) {
        this.chatModel = chatModel;
    }

    @GetMapping("/api/ai/direct")
    public String directChat(@RequestParam String prompt) {
        
        // Define highly specific runtime options for Ollama
        OllamaOptions options = OllamaOptions.create()
                .withModel("llama3.2")
                .withTemperature(0.2f)        // Lower temperature = more deterministic
                .withNumPredict(100);         // Limit the response to ~100 tokens max

        // Wrap the message and custom options into a formal Prompt object
        Prompt formalPrompt = new Prompt(new UserMessage(prompt), options);
        
        // Call the model directly to get a complete ChatResponse wrapper object
        return chatModel.call(formalPrompt)
                .getResult()
                .getOutput()
                .getText();
    }
}
Use code with caution.

2. Advanced ChatClient Capabilities

If you prefer sticking with the fluent ChatClient API, it provides incredibly convenient ways to handle advanced conversational features like setting context rules (System Prompts) and tracking memory (Chat History).

Adding a System Prompt & Conversation Memory

This example turns the client into a specific persona (a strict pirate coder) and uses an in-memory advisor to remember what the user said in previous API requests:
java
package com.example.ai.controller;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.advisor.PromptChatMemoryAdvisor;
import org.springframework.ai.chat.memory.InMemoryChatMemory;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class AdvancedChatController {

    private final ChatClient chatClient;

    public AdvancedChatController(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder
                // 1. Establish a permanent System Prompt (Persona/Rules) for this client
                .defaultSystem("You are a grumpy 17th-century pirate who is also a Senior Java Developer. Reply in character.")
                // 2. Attach an advisor to automatically manage conversational state/memory
                .defaultAdvisors(new PromptChatMemoryAdvisor(new InMemoryChatMemory()))
                .build();
    }

    @GetMapping("/api/ai/advanced")
    public String advancedChat(
            @RequestParam String prompt, 
            @RequestParam(defaultValue = "default-user-session") String sessionId) {
        
        return this.chatClient.prompt()
                .user(prompt)
                // The conversation advisor checks this ID to retrieve past messages
                .advisors(a -> a.param(PromptChatMemoryAdvisor.CHAT_MEMORY_CONVERSATION_ID_KEY, sessionId))
                .call()
                .content();
    }
}

Step B: Use ChatClient with .entity()

Instead of calling .content() to fetch a raw String, use .entity(MovieReview.class). Spring AI will automatically instruct Ollama to output JSON and then deserialize it directly into your Java record.
java
package com.example.ai.controller;

import com.example.ai.dto.MovieReview;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class StructuredOutputController {

    private final ChatClient chatClient;

    public StructuredOutputController(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder.build();
    }

    @GetMapping("/api/ai/review")
    public MovieReview getStructuredReview(@RequestParam String movieName) {
        
        return this.chatClient.prompt()
                .user("Provide a detailed analysis of the movie: " + movieName)
                .call()
                .entity(MovieReview.class); // Magic happens here: string to Java Object transformation
    }
}
