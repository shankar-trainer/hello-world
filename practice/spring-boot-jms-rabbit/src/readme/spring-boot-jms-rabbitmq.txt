To integrate RabbitMQ with Spring Boot, you need to use the Spring AMQP framework via the standard starter dependency. Spring Boot provides comprehensive auto-configuration, eliminating manual setup for connection factories and message templates.

For Maven (pom.xml):xml

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-amqp</artifactId>
</dependency>

<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.17.2</version>
</dependency>


For Gradle (build.gradle):groovyimplementation 'org.springframework.boot:spring-boot-starter-amqp'

2. Configure RabbitMQ ConnectionsDefine your server settings in src/main/resources/application.properties or application.yml. If you are running RabbitMQ locally (e.g., via Docker), Spring Boot automatically attempts to connect to localhost:5672 with the guest/guest credentials.yamlspring:
  rabbitmq:
    host: localhost
    port: 5672
    username: guest
    password: guest


3. Setup Infrastructure ConfigurationCreate a configuration class to declare the Queue, 

Exchange, and the Binding that links them together.
java

import org.springframework.amqp.core.*;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class RabbitMQConfig {

    public static final String QUEUE_NAME = "myAppQueue";
    public static final String EXCHANGE_NAME = "myAppExchange";
    public static final String ROUTING_KEY = "myAppRoutingKey";

    // 1. Declare the Queue
    @Bean
    public Queue queue() {
        return new Queue(QUEUE_NAME, true); // true = durable queue
    }

    // 2. Declare the Exchange (Direct Exchange example)
    @Bean
    public DirectExchange exchange() {
        return new DirectExchange(EXCHANGE_NAME);
    }

    // 3. Bind the Queue to the Exchange using a Routing Key
    @Bean
    public Binding binding(Queue queue, DirectExchange exchange) {
        return BindingBuilder.bind(queue).to(exchange).with(ROUTING_KEY);
    }
}


4. Create a Message Producer (Publisher).

Inject the auto-configured RabbitTemplate to easily transmit messages downstream.
java

import org.springframework.amqp.rabbit.core.RabbitTemplate;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class MessageProducer {

    @Autowired
    private RabbitTemplate rabbitTemplate;

    public void sendMessage(String message) {
        System.out.println("Sending message: " + message);
        rabbitTemplate.convertAndSend(
            RabbitMQConfig.EXCHANGE_NAME, 
            RabbitMQConfig.ROUTING_KEY, 
            message
        );
    }
}

5. Create a Message Consumer (Listener)

Use the @RabbitListener annotation on any managed bean method to asynchronously process arriving queue contents.
java

import org.springframework.amqp.rabbit.annotation.RabbitListener;
import org.springframework.stereotype.Component;

@Component
public class MessageConsumer {

    @RabbitListener(queues = RabbitMQConfig.QUEUE_NAME)
    public void receiveMessage(String message) {
        System.out.println("Received message from queue: " + message);
        // Process message logic here
    }
}

To send JSON data using RabbitMQ in Spring Boot, you must configure a Jackson2JsonMessageConverter bean. Overriding this with a Jackson converter ensures objects are automatically serialized to JSON before they are sent.Here is a complete, step-by-step guide to setting up the producer.

@RabbitListener method shouldn't typically use instanceof checks on an Object payload



then how to use for both string and json data

Using an Object payload coupled with instanceof checks is an anti-pattern in Spring AMQP because it bypasses Spring's built-in message conversion infrastructure, turning your listener into a manual deserializer.

Instead of writing manual type checks, Spring provides idiomatic ways to handle multiple payload types cleanly.

1. The Idiomatic Way: Multi-Method Listeners (@RabbitHandler)
The cleanest way to handle different types (like a raw String and a JSON-mapped object) is to use a class-level @RabbitListener combined with method-level @RabbitHandler annotations. Spring will automatically inspect the incoming message headers or content and route it to the correct method.

Java
@Component
@RabbitListener(queues = "my-queue")
public class MyMultiTypeListener {

    @RabbitHandler
    public void handleString(String payload) {
        // Automatically handles plain text / string messages
        System.out.println("Received String: " + payload);
    }

    @RabbitHandler
    public void handleJson(MyDto payload) {
        // Automatically deserializes JSON into your DTO
        System.out.println("Received JSON DTO: " + payload.getName());
    }
}
2. The Dynamic Way: Using Jackson's JsonNode
If your messages can arrive as either a raw JSON string or a fully structured JSON object and you want to parse them dynamically within a single method without hardcoding multiple DTOs, accept Jackson's JsonNode instead of an Object.

Java
@RabbitListener(queues = "my-queue")
public void handleMessage(JsonNode payload) {
    if (payload.isTextual()) {
        String text = payload.asText();
        // Handle raw string case
    } else {
        // Handle structured JSON node case
        String name = payload.get("name").asText();
    }
}
3. Configure a ContentTypeDelegatingMessageConverter
If your producers send messages with different __ContentTypeId__ or standard MIME headers (e.g., text/plain vs application/json), you can configure a delegating converter in your Spring configuration. This tells RabbitMQ how to convert payloads before they even reach your listener method signature:

Java
@Bean
public MessageConverter messageConverter() {
    ContentTypeDelegatingMessageConverter converter = new ContentTypeDelegatingMessageConverter();
    converter.addDelegate("text/plain", new Jackson2JsonMessageConverter()); // or StringMessageConverter
    converter.addDelegate("application/json", new Jackson2JsonMessageConverter());
    return converter;
}
