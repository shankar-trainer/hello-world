This error occurs because you are trying to save a Chapters entity (com.cts.model.Chapters) that references a Book entity (com.cts.model.Book) which has not yet been saved to the database. Hibernate sees the Book as "transient" (new, not in the database) and refuses to save the Chapters record because it would violate foreign key constraints. 
In a bidirectional relationship, you must ensure that when you persist the child (Chapters), the parent (Book) is already persisted or managed. 
Here are the solutions to fix this, ordered by best practice:
1. Add Cascade to the Relationship (Best Solution) 
You need to tell Hibernate to automatically save the Book whenever a Chapters object is saved. Add cascade = CascadeType.PERSIST or CascadeType.ALL to your @ManyToOne mapping in the Chapters entity. 
In Chapters.java:
java
@Entity
public class Chapters {
    // ...
    
    // Add CascadeType.PERSIST or ALL
    @ManyToOne(cascade = CascadeType.ALL) 
    @JoinColumn(name = "book_id")
    private Book book;
    
    // ...
}
2. Save the Parent First
If you do not want to use cascading, you must save the Book instance first, which will give it an ID, and then save the Chapters.
