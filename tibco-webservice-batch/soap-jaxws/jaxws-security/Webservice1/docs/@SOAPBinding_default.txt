If the @SOAPBinding(style = Style.RPC) annotation is not explicitly provided in a JAX-WS web service, the default value for the style attribute is Style.DOCUMENT. 

In addition to the style attribute, the @SOAPBinding annotation also has defaults for use and parameterStyle. Below is a breakdown of the default configuration for JAX-WS: 

Default @SOAPBinding Configuration 
If the annotation is omitted entirely or used without parameters, the following defaults apply according to the Oracle JAX-WS Documentation:
style: SOAPBinding.Style.DOCUMENT
use: SOAPBinding.Use.LITERAL
parameterStyle: SOAPBinding.ParameterStyle.WRAPPED 

Comparison of Styles
Feature 	Style.DOCUMENT (Default)	Style.RPC
Structure	The SOAP message body contains an XML document that can be validated against an XSD schema.	The SOAP message body contains an XML representation of a method call (parameters and return values).
WSDL Definition	Typically defines complex types in the <types> section of the WSDL.	Defines message parts directly in the <message> section; the <types> section is often empty.
Coupling	Loosely coupled; changes to method parameters don't necessarily break the XML schema.	Tightly coupled; the XML structure is strictly derived from the method signature.
WS-I Compliance	Considered the standard for modern, WS-I compliant web services.	Historically common but less flexible for complex data structures.
Usage Example
If you do not specify the annotation, the Java runtime treats the service as if it were annotated as follows:
java
@SOAPBinding(
    style = SOAPBinding.Style.DOCUMENT, 
    use = SOAPBinding.Use.LITERAL, 
    parameterStyle = SOAPBinding.ParameterStyle.WRAPPED
)
