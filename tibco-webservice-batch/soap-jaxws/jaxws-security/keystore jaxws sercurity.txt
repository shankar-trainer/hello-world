In JAX-WS, security is typically handled at two levels: Transport Level (HTTPS/SSL) and Message Level (WS-Security). Both require a Java KeyStore (JKS) or PKCS12 file to store certificates and private keys. 
1. Create a KeyStore

Before writing code, use the Java keytool utility to generate your keystore. For a client to trust a server, the server's certificate must be in the client's truststore. 
Generate a private key:
keytool -genkeypair -alias clientkey -keyalg RSA -keystore client_keystore.jks -storepass password
Export a certificate:
keytool -exportcert -alias clientkey -file client.cer -keystore client_keystore.jks
Import to a truststore:
keytool -importcert -alias serverkey -file server.cer -keystore client_truststore.jks 

2. Transport Level Security (HTTPS/SSL) 

For 2-way SSL (where the client also provides a certificate), you must point JAX-WS to your keystore programmatically or via system properties. 
Programmatic Configuration
You can use the BindingProvider to set a custom SSLSocketFactory containing your keystore. 
java
import javax.xml.ws.BindingProvider;
import com.sun.xml.ws.developer.JAXWSProperties; // For JAX-WS RI

// Initialize your service
MyService service = new MyService();
MyPort port = service.getMyPort();

// Get the request context
Map<String, Object> ctx = ((BindingProvider) port).getRequestContext();

// Set the SSLSocketFactory (requires a pre-configured SSLContext)
ctx.put(JAXWSProperties.SSL_SOCKET_FACTORY, myCustomSslContext.getSocketFactory());
Source: Coderanch: Setting Keystore Programmatically
System Property Method
The simplest way for standalone clients is to set global JVM properties:
System.setProperty("javax.net.ssl.keyStore", "path/to/client_keystore.jks");
System.setProperty("javax.net.ssl.keyStorePassword", "password");
System.setProperty("javax.net.ssl.trustStore", "path/to/client_truststore.jks");
System.setProperty("javax.net.ssl.trustStorePassword", "password"); 

3. Message Level Security (WS-Security)

WS-Security (WSS) signs or encrypts the SOAP body itself. This is often implemented using the Apache CXF or WSS4J libraries. 
CXF Client Configuration Example 
Define a properties file (e.g., client.properties) to link the keystore:
properties
org.apache.ws.security.crypto.provider=org.apache.ws.security.components.crypto.Merlin
org.apache.ws.security.crypto.merlin.keystore.type=jks
org.apache.ws.security.crypto.merlin.keystore.password=password
org.apache.ws.security.crypto.merlin.keystore.alias=clientkey
org.apache.ws.security.crypto.merlin.keystore.file=client_keystore.jks

Inject these into the JAX-WS BindingProvider:
java
BindingProvider bp = (BindingProvider) port;
bp.getRequestContext().put("security.signature.properties", "client.properties");
bp.getRequestContext().put("security.encryption.properties", "client.properties");
