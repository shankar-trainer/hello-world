To disable Ollama from starting automatically on boot in Bodhi Linux (which manages background services via systemd), stop and disable the systemd service using your terminal.

Step-by-Step Instructions

1. Stop the running Ollama service:bash
sudo systemctl stop ollama
Use code with caution.
   ```
2. Disable the service from auto-starting on boot:
   bash sudo systemctl disable ollama    
3. Optional: Mask the service (if you want to completely block it from being triggered by other apps or system events):
   bash sudo systemctl mask ollama.service    
To run Ollama manually later on demand, you can start it with:
bash ollama serve 
(Or simply run the ollama command, which will launch it when needed).
If you want to re-enable Ollama to start automatically again later, you can run sudo systemctl enable ollama. Let me know if you run into any issues with the service!
