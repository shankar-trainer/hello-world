1. Run xrandr to list your connected and disconnected display outputs:bash
xrandr
Use code with caution.
2. Look for the name of your internal display (e.g., eDP-1 or LVDS-1) and your projector port (e.g., HDMI-1 or HDMI-2).
3. Turn off the internal display and enable only the projector:bash
xrandr --output eDP-1 --off --output HDMI-1 --auto


lxrandr -- dialox box to select monitor or projector

bash
# Show connected displays
xrandr

# Set resolution
xrandr --output HDMI-1 --mode 1920x1080

# Set refresh rate
xrandr --output HDMI-1 --rate 60

# Rotate display
xrandr --output HDMI-1 --rotate left

# Turn off a display
xrandr --output HDMI-1 --off
