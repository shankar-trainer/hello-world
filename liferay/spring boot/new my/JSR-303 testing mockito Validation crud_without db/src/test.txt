To test a Spring MVC controller that interacts with a Spring Data JPA repository, use Spring Boot's @WebMvcTest combined with Mockito to mock the database layer and isolate your web components.Here is a complete, production-ready example of how to configure and write tests for your Spring MVC and JPA layers.1. Build the Core ComponentsBefore writing the test, establish the foundational Entity, Repository, and Controller classes.JPA Entityjavapackage com.example.demo.model;

import jakarta.persistence.*;

@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String name;

    // Constructors, Getters, and Setters
    public User() {}
    public User(Long id, String name) {
        this.id = id;
        this.name = name;
    }
    public Long getId() { return id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

JPA Repositoryjavapackage com.example.demo.repository;

import com.example.demo.model.User;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

@Repository
public interface UserRepository extends JpaRepository<User, Long> {
}
Use code with caution.Spring MVC Controllerjavapackage com.example.demo.controller;

import com.example.demo.model.User;
import com.example.demo.repository.UserRepository;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/users")
public class UserController {

    private final UserRepository userRepository;

    // Constructor injection is preferred over @Autowired
    public UserController(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    @GetMapping("/{id}")
    public ResponseEntity<User> getUserById(@PathVariable Long id) {
        return userRepository.findById(id)
                .map(ResponseEntity::ok)
                .orElse(ResponseEntity.notFound().build());
    }
}

Write the Web Layer Test (MockMvc)To efficiently test your Spring MVC logic (routing, HTTP statuses, and JSON serialization) without starting a heavy database connection, write a slice test using @WebMvcTest. Use @MockBean (or @MockitoBean in newer Boot versions) to bypass the actual JPA execution.javapackage com.example.demo.controller;

import com.example.demo.model.User;
import com.example.demo.repository.UserRepository;
import org.junit.jupiter.api.Test;
import org.mockito.Mockito;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.test.context.bean.override.mockito.MockitoBean; // Use @MockBean if on Boot < 3.4
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;

import java.util.Optional;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

@WebMvcTest(UserController.class)
public class UserControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @MockitoBean // Automatically injects a mocked version into UserController
    private UserRepository userRepository;

    @Test
    public void shouldReturnUserWhenExists() throws Exception {
        // Given
        User mockUser = new User(1L, "Alice");
        Mockito.when(userRepository.findById(1L)).thenReturn(Optional.of(mockUser));

        // When & Then
        mockMvc.perform(get("/api/users/1")
                .accept(MediaType.APPLICATION_JSON))
                .andExpect(status().isOk())
                .andExpect(content().contentType(MediaType.APPLICATION_JSON))
                .andExpect(jsonPath("$.id").value(1))
                .andExpect(jsonPath("$.name").value("Alice"));
    }

    @Test
    public void shouldReturn404WhenUserNotFound() throws Exception {
        // Given
        Mockito.when(userRepository.findById(2L)).thenReturn(Optional.empty());

        // When & Then
        mockMvc.perform(get("/api/users/2"))
                .andExpect(status().isNotFound());
    }
}

3. Write the JPA Persistence Layer Test (Optional)If you also need to ensure that your custom queries inside your JPA repository function properly, test that slice separately using @DataJpaTest. This configuration runs tests against a lightweight, embedded database (like H2) and automatically rolls back transactions after each run.javapackage com.example.demo.repository;

import com.example.demo.model.User;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.orm.jpa.DataJpaTest;

import java.util.Optional;

import static org.assertj.core.api.Assertions.assertThat;

@DataJpaTest
public class UserRepositoryTest {

    @Autowired
    private UserRepository userRepository;

    @Test
    public void shouldSaveAndFindUser() {
        // Given
        User user = new User(null, "Bob");
        User savedUser = userRepository.save(user);

        // When
        Optional<User> foundUser = userRepository.findById(savedUser.getId());

        // Then
        assertThat(foundUser).isPresent();
        assertThat(foundUser.get().getName()).isEqualTo("Bob");
    }
}
Use code with caution.Summary of Testing Strategies@WebMvcTest: Focuses strictly on your MVC controllers. It configures the Web MVC infrastructure (routing, validation, filters) but skips initializing your databases or repositories.@DataJpaTest: Focuses strictly on testing repositories and entities. It configures an in-memory database and logs SQL queries, leaving the web layer out entirely.MockMvc: Simulates incoming HTTP requests without running an expensive network server.If you would like to expand this suite, let me know:Whether your application utilizes a Service layer between the controller and repository.If you are managing POST/PUT payloads that require request validation.Your preference for either JUnit 5 or TestNG.
