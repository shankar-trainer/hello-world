The code you've written is actually quite close to being "correct" in terms of thread safety, but there is a subtle distinction between thread safety (the final value of $p$) and predictable output (the order of numbers printed).If you are seeing numbers that look "incorrect" (like 1,2,4,3,5,6,), here is a breakdown of why that happens.1. Synchronization vs. Print OrderThe increment() method is synchronized static. This means:Only one thread can execute the increment at a time.The value of p will always be incremented correctly (no "lost updates").By the end of the program, p will always be 7.The "Problem": While the incrementing is synchronized, the printing is not.Here is the sequence of events that often causes "incorrect" looking output:Thread A calls increment(). It gets the value 1 and increments $p$ to 2.Thread B calls increment(). It gets the value 2 and increments $p$ to 3.Thread B reaches the System.out.print statement first and prints 2,.Thread A finally reaches its print statement and prints 1,.Even though the math is correct, the console output appears out of order because System.out.print happens outside the synchronized block.2. Post-Increment BehaviorInside your method, you are using:return Test.p++;This is a post-increment. It returns the value of $p$ before the increment happens.If you want the first number printed to be 2, you should use return ++Test.p;.3. Execution Race ConditionSince t2.start() and t3.start() run in parallel, there is no guarantee which thread starts first or which one finishes its loop first. The CPU decides how to slice the time between them.How to get a "Correct" (Sequential) OutputIf you want the output to be exactly 1,2,3,4,5,6,, you need to synchronize the entire operation (incrementing AND printing) so that no other thread can sneak in between the calculation and the display.Modified increment method:Javastatic void incrementAndPrint() {
    // Synchronize on the class lock to ensure one thread
    // finishes the print before the next one starts
    synchronized(Test.class) {
        System.out.print(Test.p++ + ",");
    }
}
