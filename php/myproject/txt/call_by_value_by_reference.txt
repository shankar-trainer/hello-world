In PHP, the distinction between call by value and call by reference determines whether a function works with a copy of your data or the original data itself.

1. Call by Value (Default)

When you pass a variable "by value," PHP creates a copy of the variable's content and passes it to the function. Any changes made to the parameter inside the function stay inside the function; the original variable remains untouched.

Example:
PHP
<?php
function addFive($num) {
    $num += 5;
    echo "Inside function: " . $num . "\n";
}

$original = 10;
addFive($original);

echo "Outside function: " . $original; 
?>
Output:

Inside function: 15
Outside function: 10 (The original didn't change!)

2. Call by Reference
When you pass "by reference," you are passing the memory address of the variable. You do this by placing an ampersand (&) before the parameter name in the function definition. Now, the function and the calling code are both looking at the exact same data.

Example:
PHP
<?php
function addFiveByRef(&$num) { // Note the & symbol
    $num += 5;
    echo "Inside function: " . $num . "\n";
}

$original = 10;
addFiveByRef($original);

echo "Outside function: " . $original;
?>

Output:

Inside function: 15
Outside function: 15 (The original was updated!)

Key Differences at a Glance
Feature	Call by Value	Call by Reference
Syntax	function Name($var)	function Name(&$var)
Data	Works on a copy.	Works on the original.
Memory	Uses more memory (for the copy).	More memory-efficient for large data.
Risk	Safer; no accidental side effects.	Risks changing data unexpectedly.
A Quick Note on Objects
In modern PHP (version 5 and later), objects are passed by "handle." While it looks like call by reference (because changing a property inside a function updates the original object), it is technically a copy of the pointer to that object. If you want to replace the entire object instance within a function, you would still need the & syntax.
