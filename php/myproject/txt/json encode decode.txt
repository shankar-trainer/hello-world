PHP provides two primary built-in functions for handling JSON: json_encode() and json_decode().

1. json_encode(): Convert PHP to JSON.
This function converts a PHP value (usually an array or object) into a JSON string.

<?php
// PHP Associative Array

$data = [
    "name" => "Alice",
    "age" => 25,
    "skills" => ["PHP", "JSON", "SQL"]
];

// Encode to JSON string
$jsonString = json_encode($data);

echo $jsonString; 
// Output: {"name":"Alice","age":25,"skills":["PHP","JSON","SQL"]}
?>


2. json_decode(): Convert JSON to PHP.

This function converts a JSON string back into a PHP variable. 
By default, it returns a PHP object (stdClass). 
To get an associative array, set the second parameter to true.

<?php
    $jsonString = '{"name":"Alice","age":25,"skills":["PHP","JSON","SQL"]}';

    // 1. Decode as an Object (Default)
    $obj = json_decode($jsonString);
    echo $obj->name; // Output: Alice

    // 2. Decode as an Associative Array
    $arr = json_decode($jsonString, true);
    echo $arr["name"]; // Output: Alice
?>

Key Differences & TipsDouble Quotes: For decoding to work, JSON keys and string values must use double quotes.
Error Handling: Use json_last_error_msg() to find out why a conversion failed.

Pretty Print: 

When encoding, use JSON_PRETTY_PRINT to make the output human-readable.phpecho json_encode($data, JSON_PRETTY_PRINT);

External Files: You can read JSON from a file using file_get_contents() before decoding it.
