Error handling in PHP forms involves validating user input and providing feedback without crashing the script. 

A common approach is to collect all validation errors in an array and display them to the user after submission.

Basic Form Error Handling ExampleThis example demonstrates how to catch empty fields and validate an email address, then display errors directly on the same page.

php
<?php
// Initialize variables and error array
$name = $email = "";
$errors = [];

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // 1. Sanitize and validate Name
    if (empty($_POST["name"])) {
        $errors['name'] = "Name is required";
    } else {
        $name = htmlspecialchars(trim($_POST["name"]));
    }

    // 2. Sanitize and validate Email
    if (empty($_POST["email"])) {
        $errors['email'] = "Email is required";
    } else {
        $email = htmlspecialchars(trim($_POST["email"]));
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
            $errors['email'] = "Invalid email format";
        }
    }

    // 3. Check if any errors occurred
    if (empty($errors)) {
        // Proceed with data processing (e.g., save to database)
        echo "Form submitted successfully!";
        exit();
    }
}
?>

<!-- HTML Form -->
<form method="post" action="<?php echo htmlspecialchars($_SERVER["PHP_SELF"]);?>">
    <label>Name:</label>
    <input type="text" name="name" value="<?php echo $name; ?>">
    <span class="error" style="color:red;"><?php echo $errors['name'] ?? ''; ?></span>
    <br><br>

    <label>Email:</label>
    <input type="text" name="email" value="<?php echo $email; ?>">
    <span class="error" style="color:red;"><?php echo $errors['email'] ?? ''; ?></span>
    <br><br>

    <input type="submit" value="Submit">
</form>
Key Error Handling Concepts

Array-based Collection: Storing errors in an array (e.g., $errors[]) allows you to show multiple validation issues at once, providing a better user experience than stopping the script after the first error.

Input Preservation: Use the value attribute in HTML tags to echo the user’s submitted data back into the form if validation fails, preventing them from having to re-type everything.

Sanitization: Use functions like htmlspecialchars() and trim() to clean data before displaying or processing it, which helps prevent security risks like Cross-Site Scripting (XSS).

Try-Catch Blocks: For more severe operational errors (like database connection failures), use try...catch blocks to handle Exceptions gracefully instead of showing raw system errors.

Custom Error Handlers: You can use set_error_handler() to define a global function that catches non-fatal warnings and notices, allowing you to log them to a file while showing a friendly message to the user.
