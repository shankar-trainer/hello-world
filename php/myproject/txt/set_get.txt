 In PHP, the most direct way to set and get properties is through Visibility Modifiers (public, private, or protected). While public properties are easy to access, using Getters and Setters with private properties is the industry standard for keeping your data secure and valid.

Here is how you can implement this.

1. The Standard Getter and Setter Method
This is the most common approach. It allows you to "gatekeep" your data—for example, ensuring a user's age isn't a negative number before saving it.

PHP

<?php

class User {
    // Private properties: cannot be accessed directly outside the class
    private string $name;
    private int $age;

    // Setter for Name
    public function setName(string $name): void {
        $this->name = $name;
    }

    // Getter for Name
    public function getName(): string {
        return $this->name;
    }

    // Setter for Age (with logic/validation)
    public function setAge(int $age): void {
        if ($age < 0) {
            echo "Error: Age cannot be negative.";
            return;
        }
        $this->age = $age;
    }

    // Getter for Age
    public function getAge(): int {
        return $this->age;
    }
}

// Usage
$user = new User();
$user->setName("Alice");
$user->setAge(25);

echo $user->getName(); // Output: Alice
echo $user->getAge();  // Output: 25
?>


2. The "Magic" Method Approach (__set and __get)

If you don't want to write a dozen individual functions, PHP provides "Magic Methods." These are automatically triggered when you try to access a property that is private or doesn't exist.

<?php

class SmartData {
    private array $data = [];

    // Triggered when writing data
    public function __set($name, $value) {
        echo "Setting '$name' to '$value'\n";
        $this->data[$name] = $value;
    }

    // Triggered when reading data
    public function __get($name) {
        if (array_key_exists($name, $this->data)) {
            return $this->data[$name];
        }
        return "Property '$name' not found.";
    }
}

$obj = new SmartData();
$obj->username = "CyberKnight"; // Calls __set()
echo $obj->username;           // Calls __get()
?>

3. Property Hooks (PHP 8.4+)
If you are using the very latest version of PHP (8.4), you can use Property Hooks. This is a modern, concise way to define logic directly on the property without writing full methods.

PHP

class Product {
    public string $name {
        set => strtolower($value); // Always store name in lowercase
        get => ucfirst($this->name); // Always return with first letter capitalized
    }
}

Which one should you use?

Standard Getters/Setters: Use these 90% of the time. They are clear, IDE-friendly (autocompletion works), and standard in frameworks like Laravel or Symfony.

Magic Methods: Use these only for dynamic data structures (like a database row wrapper).

Public Properties: Use these only for simple "Data Transfer Objects" (DTOs) where no validation is needed.

In PHP, the __set and __get magic methods allow you to define custom behavior when accessing or modifying properties that are not directly accessible. For an example with an employee class, you could implement it like this:

php


class Employee {
    private $data = [];

    public function __set($name, $value) {
        $this->data[$name] = $value;
    }

    public function __get($name) {
        return $this->data[$name] ?? null;
    }
}

$employee = new Employee();
$employee->id = 1; // Using __set
$employee->name = "John Doe"; // Using __set

echo $employee->id; // Using __get
echo $employee->name; // Using __get

This example shows how to use __set to assign values to properties and __get to retrieve them. The __set method is called when you assign a value to a property, and the __get method is called when you access a property.
