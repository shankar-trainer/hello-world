php crud mysql example with exception handling without pdo
  try catch and throw                      To create a PHP CRUD example without PDO while using try-catch blocks and manual throw statements, you must use the MySQLi extension.

Starting with PHP 8.1, MySQLi throws exceptions by default. However, for older versions or explicit control, you should enable strict error reporting using mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT) to ensure database errors trigger a mysqli_sql_exception that your try-catch block can handle.PHP 

CRUD Example with Exception Handling.
This example demonstrates how to Create, Read, Update, and Delete records while manually throwing custom exceptions for business logic (like missing records) and catching database-level errors.php

<?php
// Enable MySQLi exception reporting for all versions
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);

$host = 'localhost';
$user = 'root';
$pass = '';
$db   = 'test_db';

try {
    // 1. CONNECT
    $conn = new mysqli($host, $user, $pass, $db);
    
    // 2. CREATE (Insert)
    $stmt = $conn->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
    $name = "John Doe";
    $email = "john@example.com";
    $stmt->bind_param("ss", $name, $email);
    
    if (!$stmt->execute()) {
        throw new Exception("Failed to insert user."); // Manual throw
    }
    echo "Record created successfully.<br>";

    // 3. READ (Select)
    $id_to_find = 1;
    $result = $conn->query("SELECT * FROM users WHERE id = $id_to_find");
    
    if ($result->num_rows === 0) {
        // Manually throw exception if no record is found
        throw new Exception("User with ID $id_to_find not found!"); 
    }
    $user = $result->fetch_assoc();
    echo "User Found: " . $user['name'] . "<br>";

    // 4. UPDATE
    $new_name = "John Updated";
    $update_stmt = $conn->prepare("UPDATE users SET name = ? WHERE id = ?");
    $update_stmt->bind_param("si", $new_name, $id_to_find);
    $update_stmt->execute();
    echo "Record updated.<br>";

    // 5. DELETE
    $delete_id = 1;
    $conn->query("DELETE FROM users WHERE id = $delete_id");
    echo "Record deleted.<br>";

} catch (mysqli_sql_exception $e) {
    // Specifically catch database errors (connection, syntax, etc.)
    error_log("Database Error: " . $e->getMessage());
    echo "A database error occurred. Please try again later.";

} catch (Exception $e) {
    // Catch manual throws and other general exceptions
    echo "Application Error: " . $e->getMessage();

} finally {
    // Close connection regardless of success or failure
    if (isset($conn) && $conn->ping()) {
        $conn->close();
    }
}
?>
Use code with caution.Key Components Explainedmysqli_report(): This "magic line" tells MySQLi to stop being silent and instead throw a mysqli_sql_exception whenever a query fails.

try Block: Houses your CRUD logic. If any line fails or a throw is triggered, execution immediately jumps to the catch block.

throw new Exception(): Used for custom logic, such as when a query technically succeeds but returns zero results (not a DB error, but a logic error for your app).

catch (mysqli_sql_exception $e): Catches specific database errors like "table not found" or "connection refused".

finally Block: Ensures the database connection is closed or resources are cleaned up even if an error occurs.

To perform CRUD (Create, Read, Update, Delete) operations in PHP without using PDO, you can use the MySQLi extension (MySQL Improved).

 By default, MySQLi does not throw exceptions for query errors; however, you can enable exception handling globally using mysqli_report().
 
1. Enable Exception Reporting 
In your database connection file, use MYSQLI_REPORT_ALL or MYSQLI_REPORT_STRICT to force MySQLi to throw mysqli_sql_exception instead of just returning false. 


<?php
// db.php - Database Connection
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);

try {
    $host = 'localhost';
    $user = 'root';
    $pass = '';
    $db   = 'my_database';

    $conn = new mysqli($host, $user, $pass, $db);
    $conn->set_charset("utf8mb4");
} catch (mysqli_sql_exception $e) {
    error_log($e->getMessage());
    exit('Database connection failed');
}
?>

                   To implement a robust CRUD (Create, Read, Update, Delete) system in PHP, using the PDO (PHP Data Objects) extension is the best practice. It provides built-in support for exception handling and prepared statements to prevent SQL injection.

1. Database Connection with Exception HandlingThe first step is establishing a connection. Using a try-catch block ensures that if the database is down or credentials are wrong, you can handle the error gracefully without exposing sensitive server details.php<?php
// db.php - Database Configuration
$host = 'localhost';
$db   = 'my_database';
$user = 'root';
$pass = '';
$charset = 'utf8mb4';

$dsn = "mysql:host=$host;dbname=$db;charset=$charset";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION, // Enables exceptions
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    $pdo = new PDO($dsn, $user, $pass, $options);
} catch (\PDOException $e) {
    // Log the error and stop execution
    error_log("Connection failed: " . $e->getMessage());
    die("A database error occurred. Please try again later.");
}
?>
