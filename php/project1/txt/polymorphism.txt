Polymorphism in PHP allows objects of different classes to be treated as instances of a common parent class or interface. 
This enables a single method call to behave differently based on the specific object that is executing it.
Polymorphism Using InterfacesInterfaces define a "contract" that classes must follow. 
This ensures that diverse classes provide the same method names, allowing them to be used interchangeably.

php

<?php
// Define a common interface
interface Shape {
    public function calculateArea();
}

// Class for a Circle
class Circle implements Shape {
    private $radius;

    public function __construct($radius) {
        $this->radius = $radius;
    }

    public function calculateArea() {
        return pi() * pow($this->radius, 2);
    }
}

// Class for a Rectangle
class Rectangle implements Shape {
    private $width;
    private $height;

    public function __construct($width, $height) {
        $this->width = $width;
        $this->height = $height;
    }

    public function calculateArea() {
        return $this->width * $this->height;
    }
}

// Polymorphic behavior: A function that works with any "Shape"
function printArea(Shape $shape) {
    echo "Area: " . $shape->calculateArea() . "\n";
}

$shapes = [new Circle(5), new Rectangle(10, 2)];

foreach ($shapes as $shape) {
    printArea($shape); // Same method call, different result based on object type
}
?>
Use code with caution.

Polymorphism Using Abstract Classes
Abstract classes allow you to provide some shared logic while forcing child classes to implement specific "abstract" methods.

php<?php
abstract class Animal {
    // Abstract method must be implemented by subclasses
    abstract public function makeSound();

    // Shared method for all animals
    public function sleep() {
        echo "Sleeping... Zzz\n";
    }
}

class Dog extends Animal {
    public function makeSound() {
        return "Woof!";
    }
}

class Cat extends Animal {
    public function makeSound() {
        return "Meow!";
    }
}

$animals = [new Dog(), new Cat()];

foreach ($animals as $animal) {
    echo $animal->makeSound() . "\n"; // Outputs "Woof!" then "Meow!"
}
?>

Use code with caution.
Key Benefits
Flexibility: You can write code that works with a broad type (like Shape) rather than specific classes (like Circle).
Scalability: You can add a new class (e.g., Triangle) that implements the Shape interface without changing existing functions like printArea().
Code Cleanliness: It removes the need for complex if/else or switch statements to check an object's type.

In PHP, runtime polymorphism is achieved through method overriding. It allows a subclass to provide a specific implementation for a method already defined in its parent class or interface. The decision of which method to execute is made at runtime based on the actual object type being used.Code Example: Shape CalculationThis example uses an interface to define a standard behavior (calculateArea), which different shape classes implement in their own way.php<?php
// 1. Define a common interface or parent class
interface Shape {
    public function calculateArea();
}

// 2. Implement the interface in different classes (Subclasses)
class Circle implements Shape {
    private $radius;

    public function __construct($radius) {
        $this->radius = $radius;
    }

    public function calculateArea() {
        return pi() * pow($this->radius, 2);
    }
}

class Square implements Shape {
    private $side;

    public function __construct($side) {
        $this->side = $side;
    }

    public function calculateArea() {
        return $this->side * $this->side;
    }
}

// 3. Runtime Polymorphism in action
function displayArea(Shape $shape) {
    // The specific calculateArea() method is determined at RUNTIME
    echo "The area is: " . $shape->calculateArea() . PHP_EOL;
}

$circle = new Circle(5);
$square = new Square(4);

displayArea($circle); // Executes Circle's version
displayArea($square); // Executes Square's version
?>
Use code with caution.
Key Concepts
    Method Overriding: A child class defines a method with the same name and signature as its parent, effectively "overriding" the parent's logic.
    Interchangeability: You can treat different objects (like Circle and Square) as the same base type (Shape), which simplifies code and reduces conditional logic.
    Dynamic Binding: PHP is a dynamically typed language, meaning it doesn't know which class method to call until the code is actually running and the object instance is identified.
