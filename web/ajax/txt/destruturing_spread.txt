Destructuring and spread syntax (ES6) are essential JavaScript features for writing cleaner, more efficient code by reducing verbosity when handling data structures. Destructuring extracts values from arrays or objects into distinct variables, while the spread operator (...) expands iterables into individual elements or copies properties.

Destructuring
    Destructuring acts as a "fast unpacker" for arrays and objects.
    Object Destructuring: Extracts properties using {}. Variables must match property names.

    javascript
    const user = { name: 'Alice', age: 25 };
    const { name, age } = user; // name = 'Alice', age = 25
    Array Destructuring: Extracts items using []. Order matters.

    javascript
        const colors = ['red', 'green', 'blue'];
        const [first, second] = colors; // first = 'red', second = 'green'
        Default Values: Prevents undefined if data is missing.
    javascript
        const { role = 'user' } = {}; // role = 'user'

Spread Operator (...)
The spread operator "spreads" an array or object into its individual elements or properties.

Expanding Arrays: Combines or clones arrays efficiently.
javascript
    const arr1 = [1, 2];
    const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]

    Object Copying/Merging: Creates shallow copies or merges objects.
    javascript
    const original = { a: 1 };
    const copy = { ...original, b: 2 }; // { a: 1, b: 2 }


Rest Parameter (...)
While using the same ... syntax, the rest parameter collects multiple elements into an array, often used in destructuring.

    javascript
    const [first, ...rest] = [1, 2, 3, 4]; // first = 1, rest = [2, 3, 4]
    Combined Example

    javascript
    const user = { id: 1, name: 'Alice', role: 'admin' };
    // Extract name, rest goes into "details"
    const { name, ...details } = user;
    // Clone and update
    const updatedUser = { ...user, active: true };
