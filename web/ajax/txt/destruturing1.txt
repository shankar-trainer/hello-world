JavaScript destructuring assignment is a powerful syntax that makes it possible to unpack values from arrays or properties from objects into distinct variables in a concise and readable way. It was introduced in ES6 (ECMAScript 2015) and does not modify the original array or object.

Array Destructuring
    Array destructuring allows you to extract elements based on their position (index).
    Basic Assignment: Values are assigned to variables based on their order in the array.

javascript
    const fruits = ["Bananas", "Oranges", "Apples"];
    const [fruit1, fruit2, fruit3] = fruits;
    console.log(fruit1); // "Bananas"
    Skipping Values: You can ignore unwanted elements by using commas to skip positions.

javascript
    const fruits = ["Bananas", "Oranges", "Apples"];
    const [fruit1, , fruit3] = fruits;
    console.log(fruit1); // "Bananas"
    console.log(fruit3); // "Apples"

Rest Pattern: The rest pattern (...) collects all remaining elements into a new array. It must be the last element in the destructuring pattern.
    javascript
    const numbers = [10, 20, 30, 40, 50];
    const [a, b, ...rest] = numbers;
    console.log(a);    // 10
    console.log(rest); // [30, 40, 50]

    Swapping Variables: Destructuring provides an easy way to swap variable values without a temporary variable.
    javascript
    let a = 1;
    let b = 3;
    [a, b] = [b, a];
    console.log(a); // 3
    console.log(b); // 1


Object Destructuring

    Object destructuring allows you to extract properties based on their names.
    Basic Assignment: Variables are created with the same name as the object's properties.

    javascript

    const person = { firstName: "John", lastName: "Doe", age: 50 };
    const { firstName, lastName, age } = person;
    console.log(firstName); // "John"

    Assigning to New Variable Names (Aliasing): You can extract a property and assign it to a variable with a different name using a colon (:).
    javascript
    const person = { firstName: "John", lastName: "Doe" };
    const { firstName: name, lastName: surname } = person;
    console.log(name);    // "John"
    console.log(surname); // "Doe"

    Default Values: You can provide default values in case the property is missing or undefined in the source object.
    javascript
    const { firstName, middleName = "N/A" } = person;
    console.log(middleName); // "N/A"

    Nested Destructuring: You can extract properties from nested objects in a single statement.
    javascript
    const user = {
      id: 42,
      fullName: { firstName: "Jane", lastName: "Doe" }
    };
    const { fullName: { firstName } } = user;
    console.log(firstName); // "Jane"

    Function Parameters: It is very useful for extracting specific properties from an object passed as a function argument.
    javascript
    function displayDetails({ name, age }) {
      console.log(`${name} is ${age} years old.`);
    }
    const person = { name: "Peter", age: 50 };
    displayDetails(person); // Output: Peter is 50 years old.
    Working with API Responses: It simplifies the process of extracting the necessary data from a larger JSON object returned from an API.
    React Development: It is heavily used in frameworks like React for handling props and state management (e.g., const [count, setCount] = useState(0)).
