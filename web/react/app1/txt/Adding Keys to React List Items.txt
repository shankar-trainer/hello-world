why .map uses key
In React, the .map() function uses a key prop to provide a stable identity to elements, allowing React to efficiently identify which items have changed, 
been added, or removed. This key is essential for optimizing rendering performance during list updates and ensuring correct state management for components. 

Performance Optimization: Keys help React identify which items in a list have changed, been added, or been removed, minimizing unnecessary re-renders.
Stable Identity: Keys give elements a persistent, unique identifier across re-renders.

Component State Preservation: Using unique keys, such as database IDs, ensures that component state (e.g., input values) remains with the correct item, even if the list order changes.

Avoid Using Index: While using the array index is allowed, it is not recommended if the list order changes, as it can cause issues with state and performance. 

====================
To fix this, you need to add the key prop to the top-level element being returned by your map function—in this case, 
the <tr> tag.

Since your data already has an i.id, that is the perfect candidate for a unique key.

Updated Code
JavaScript

{
    props.item
        .filter(a => a.cost >= 50)
        .sort((a, b) => a.cost - b.cost)
        .map(i => (
            <tr key={i.id}>
                <td>{i.id}</td>
                <td>{i.name}</td>
                <td>{i.cost}</td>
            </tr>
        ))
}
Why this matters
Performance: React uses the key to identify which items have changed, been added, or been removed. 
Without it, React has to re-render the entire list instead of just the specific row that changed.

Stability: Using a unique ID (like i.id) is much safer than using the array index, 
especially since you are filtering and sorting the list. If you used an index, React might get confused about which data 
belongs to which DOM element when the order changes.

Pro-tip: Always avoid using the array index as a key when the list can be reordered or filtered, as it can lead to "ghost" bugs in your UI components.
