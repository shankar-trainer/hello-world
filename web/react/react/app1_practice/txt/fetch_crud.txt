Implementing CRUD (Create, Read, Update, Delete) operations in React using the native fetch API involves using different HTTP methods for each operation, often within useEffect and event handlers in functional components. A common approach uses a free online REST API like JSONPlaceholder for examples. 

Setup
For these examples, we assume an API endpoint like https://jsonplaceholder.typicode.com and that you have a React functional component set up with useState and useEffect hooks. 
1. Read (GET)
The Read operation typically happens when a component mounts, using the useEffect hook to send a GET request and update the component's state. 

import React, { useState, useEffect } from 'react';

const ReadPosts = () => {
  const [posts, setPosts] = useState([]);
  const [isLoading, setIsLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchPosts = async () => {
      try {
        const response = await fetch('https://jsonplaceholder.typicode.com');
        if (!response.ok) {
          throw new Error('Network response was not ok');
        }
        const data = await response.json();
        setPosts(data);
      } catch (error) {
        setError(error);
      } finally {
        setIsLoading(false);
      }
    };
    fetchPosts();
  }, []);

  if (isLoading) return <p>Loading posts...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <div>
      <h2>Posts</h2>
      <ul>
        {posts.map(post => (
          <li key={post.id}>{post.title}</li>
        ))}
      </ul>
    </div>
  );
};

const createPost = async (newPost) => {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(newPost),
    });
    if (!response.ok) {
      throw new Error('Failed to create post');
    }
    const createdPost = await response.json();
    // Update state to include the new post (e.g., setPosts(prevPosts => [...prevPosts, createdPost]))
    console.log('Post created:', createdPost);
  } catch (error) {
    console.error('Error creating post:', error);
  }
};
3. Update (PUT/PATCH)
Updating an existing resource requires specifying its ID in the URL and using the PUT or PATCH method. PUT usually replaces the entire resource, while PATCH applies partial updates.

const updatePost = async (id, updatedData) => {
  try {
    const response = await fetch(`https://jsonplaceholder.typicode.com{id}`, {
      method: 'PUT', // or 'PATCH'
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify(updatedData),
    });
    if (!response.ok) {
      throw new Error('Failed to update post');
    }
    const result = await response.json();
    // Update state to reflect the changes
    console.log('Post updated:', result);
  } catch (error) {
    console.error('Error updating post:', error);
  }
};
