In a React component, setLoading is the "switch" that controls what the user sees while your data is traveling from the server to their screen.

Without it, your app might try to render empty data before it arrives, leading to crashes (like trying to map over null) or a blank, confusing screen for the user.

Why use setLoading?1. 

User Experience (UX)Fetching data takes time—anywhere from a few milliseconds to several seconds. 
setLoading allows you to show a loading state (like a spinner or "Loading..." text). 


In React, setLoading is the state updater function used to manage the boolean loading state, typically via the useState hook. This state is then used for conditional rendering to display a loader (like a spinner or a "Loading..." message) while an asynchronous operation, such as fetching data, is in progress.
