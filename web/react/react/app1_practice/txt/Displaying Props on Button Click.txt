In a React class component, "displaying props on click" usually means you want to trigger a change in the UI—like showing a piece of data passed from a parent—when a user interacts with a button.

Since props are read-only, you can’t "turn them on" directly. Instead, you use the component's state to toggle their visibility.

The Logic Flow
Initialize State: Set a boolean (like showDetails: false) in the constructor.

Create a Handler: Write a function that calls this.setState() to flip that boolean to true.

Render Conditionally: Use a logical AND (&&) or a ternary operator in the render() method to show the prop only when the state is true.

Code Example
Here is how you would implement this in a standard class component:

JavaScript

import React, { Component } from 'react';

class UserProfile extends Component {
  constructor(props) {
    super(props);
    // 1. Initialize state
    this.state = {
      isVisible: false
    };

    // Bind the handler (if not using arrow functions)
    this.toggleVisibility = this.toggleVisibility.bind(this);
  }

  // 2. The Handler function
  toggleVisibility() {
    this.setState({ isVisible: true });
  }

  render() {
    return (
      <div style={{ border: '1px solid #ccc', padding: '20px' }}>
        <h3>User: {this.props.username}</h3>
        
        {/* 3. Conditional Rendering */}
        {this.state.isVisible && (
          <p>Secret ID: {this.props.userID}</p>
        )}

        <button onClick={this.toggleVisibility}>
          Show Prop Details
        </button>
      </div>
    );
  }
}

export default UserProfile;

Key Details to Remember
Binding: In class components, standard functions don't "auto-bind" this. If you don't use an arrow function for your click handler, you must bind it in the constructor (as shown above) or your app will throw an error saying this is undefined.

The "Toggle" Variation: If you want the button to hide the prop on the second click, change your handler to:
this.setState({ isVisible: !this.state.isVisible });

Props vs. State: Remember, the data comes from the Prop, but the "permission" to show it lives in the State.
