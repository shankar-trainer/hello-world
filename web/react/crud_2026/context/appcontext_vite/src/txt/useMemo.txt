In React, useMemo is a built-in Hook used to memoize (cache) the result of a calculation between re-renders. It prevents expensive, resource-intensive functions from running unnecessarily on every render.

1. How It WorksuseMemo stores the return value of a function and only recalculates it when one of its specified dependencies changes.Initial Render: React calls your calculation function and returns its result.Subsequent Rerenders: React compares the current dependencies with the previous ones using Object.is. If they are the same, it returns the cached value. If they have changed, it re-runs the calculation and stores the new result.

2. Syntaxjavascriptimport { useMemo } from 'react';

    const memoizedValue = useMemo(() => {
      return computeExpensiveValue(a, b);
    }, [a, b]); // Dependency array

    Calculation Function: A pure function with no arguments that returns the value you want to cache.Dependencies: An array containing all reactive values (props, state, variables) used inside the calculation.

3. When to Use ItYou should primarily use useMemo for performance optimization, not as a general coding pattern.
    Expensive Calculations: When you have a slow operation (e.g., filtering a large dataset or complex math) that shouldn't re-run unless its specific inputs change.Referential Equality: To keep an object or array reference stable.

    This is crucial when passing these as props to child components wrapped in React.memo, which only skips re-rendering if props are strictly equal.Dependency Stability: When the result of one Hook is used as a dependency for another Hook (like useEffect or another useMemo).

4. When to Avoid ItSimple Calculations: For basic logic (like string concatenation), the overhead of memoization can be higher than the calculation itself.

Premature Optimization: Do not use it unless you have identified a specific performance bottleneck using tools like the React Developer Tools Profiler.React 19+: The new React Compiler automatically memoizes many values, potentially making manual useMemo calls unnecessary in newer projects.5. useMemo vs. useCallbackWhile both hooks handle memoization, they serve different purposes:useMemo: Caches the result (value) of a function.useCallback: Caches the function instance itself.



===================================================================

The useMemo Hook in React is a performance optimization tool used to memoize (cache) the result of an expensive calculation between re-renders. It ensures that a function only runs when its specific dependencies change, rather than on every render of the component.Syntaxjavascriptconst memoizedValue = useMemo(() => computeExpensiveValue(a, b), [a, b]);

First argument: A "calculation" function that returns the value you want to cache.
Second argument: An array of dependencies (props or state) that trigger a recalculation when they change.

Example: Filtering a Large ListIn this scenario, we use useMemo to ensure a large list is only filtered when the query or items change. Without it, clicking the "Toggle Theme" button would force the expensive filter to run again, even though the list hasn't changed.javascriptimport React, { useState, useMemo } from 'react';

function ProductList({ items }) {
  const [query, setQuery] = useState("");
  const [isDark, setIsDark] = useState(false);

  // useMemo caches the filtered list
  const filteredItems = useMemo(() => {
    console.log("Filtering items..."); // Only logs when query or items change
    return items.filter(item => item.name.toLowerCase().includes(query.toLowerCase()));
  }, [items, query]); // Dependencies

  return (
    <div style={{ background: isDark ? "#333" : "#fff", color: isDark ? "#fff" : "#000" }}>
      <input
        type="text"
        placeholder="Search..."
        onChange={(e) => setQuery(e.target.value)}
      />
      <button onClick={() => setIsDark(!isDark)}>Toggle Theme</button>

      <ul>
        {filteredItems.map(item => <li key={item.id}>{item.name}</li>)}
      </ul>
    </div>
  );
}

When to Use useMemoExpensive Calculations: Any logic that takes significant time (e.g., sorting 1,000+ items, complex math).
Referential Equality: When you need to pass an object or array to a child component wrapped in React.memo.

Since {} !== {} in JavaScript, useMemo keeps the same object reference between renders to prevent the child from re-rendering.Dependency

for other Hooks: If a value you created is used as a dependency in a useEffect or another useMemo, memoizing it prevents the downstream hook from firing unnecessarily.

Common MistakesOveruse: Do not wrap every variable in useMemo. For simple calculations (like 1 + 1), the overhead of the Hook itself is slower than just recalculating the value.Missing Dependencies: If you use a variable inside the function but forget to add it to the dependency array, the memoized value will become stale (outdated).React 19: Note that React 19 introduces an automatic compiler that may handle these optimizations automatically, reducing the need for manual useMemo calls in the future.
