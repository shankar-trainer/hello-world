In React, the parent component manages the state and passes the state value and the update function to its child component via props. This is known as "lifting state up" and ensures a unidirectional data flow. 

Here is an example using functional components and the useState hook:
Parent Component (ParentComponent.js)
The parent component holds the count state and a function to update it (setCount). It passes both of these as props to the ChildComponent. 

import React, { useState } from 'react';
import ChildComponent from './ChildComponent';

const ParentComponent = () => {
  // State defined in the parent component
  const [count, setCount] = useState(0);

  // Function to update the state in the parent component
  const incrementCount = () => {
    setCount(count + 1);
  };

  return (
    <div>
      <h1>Parent Component</h1>
      <p>Current Count: {count}</p>
      {/* Passing state value and update function as props */}
      <ChildComponent currentCount={count} onIncrement={incrementCount} />
    </div>
  );
};

export default ParentComponent;
 

Child Component (ChildComponent.js)

The child component receives the currentCount and the onIncrement function as props. It uses the function to trigger a state change in its parent when an event occurs (e.g., a button click). 

import React from 'react';

// Receiving props from the parent
const ChildComponent = ({ currentCount, onIncrement }) => {
  return (
    <div>
      <h2>Child Component</h2>
      <p>Count from Parent: {currentCount}</p>
      {/* Calling the parent's function to update its state */}
      <button onClick={onIncrement}>
        Increment Count in Parent
      </button>
    </div>
  );
};

export default ChildComponent;
 

Key Concepts Illustrated
Unidirectional Data Flow: Data (count) flows down from the parent to the child as a prop.

Callback Functions: To communicate up to the parent, a function defined in the parent (incrementCount) is passed down as a prop (onIncrement) and is called by the child to modify the parent's state.

Single Source of Truth: The count state is owned by the ParentComponent, making it the single source of truth for that data.

Code Example
This example shows a Parent component managing a count, while the Child component triggers the update.
jsx
import React, { useState } from 'react';

// Child Component
const ChildComponent = ({ count, onIncrement }) => {
  return (
    <div style={{ border: '1px solid black', padding: '10px', margin: '10px' }}>
      <h3>Child Component</h3>
      <p>Current Count from Parent: {count}</p>
      {/* 3. Child calls the function passed via props */}
      <button onClick={onIncrement}>Increment from Child</button>
    </div>
  );
};

// Parent Component
const ParentComponent = () => {
  // 1. Parent manages the state
  const [count, setCount] = useState(0);

  const handleIncrement = () => {
    setCount(prevCount => prevCount + 1);
  };

  return (
    <div style={{ padding: '20px' }}>
      <h1>Parent Component</h1>
      <p>Count: {count}</p>
      <hr />
      {/* 2. Parent passes state and function to Child as props */}
      <ChildComponent 
        count={count} 
        onIncrement={handleIncrement} 
      />
    </div>
  );
};

export default ParentComponent;
Use code with caution.

How it Works
State Ownership: The ParentComponent "owns" the count state.
Unidirectional Data Flow: The count value flows down to the child as a prop so it can be displayed.
Communication Upwards: The onIncrement function is also passed down. When the user clicks the button in the ChildComponent, it executes that function, which updates the state back in the parent.
Re-rendering: Once the parent's state updates, React automatically re-renders both the parent and the child with the new value.

When to use this?
Controlled Inputs: When a parent needs to know the value of a text field inside a child component.
Shared State: When multiple siblings need to stay in sync (e.g., a "Total Price" component and several "Item" components).
Modals/Popups: When a child component needs a way to tell the parent to close it.
