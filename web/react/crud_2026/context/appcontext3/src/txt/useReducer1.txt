An alternative to useState.

useReducer is usually preferable to useState when you have complex state logic that involves multiple sub-values. It also lets you optimize performance for components that trigger deep updates because you can pass dispatch down instead of callbacks.

@version — 16.8.0


=========================

useReducer is a React Hook for managing complex state logic, serving as a robust alternative to useState. 
It works by dispatching actions to a reducer function rather than directly updating state. 

Basic Syntax and Components

const [state, dispatch] = useReducer(reducer, initialState);


    Reducer Function: A pure function (state, action) => nextState that handles updates based on action types.

    Action: An object, typically with a type string and optional payload.
        
    Dispatch Function: Used to trigger state changes by sending actions to the reducer. 

When to Choose useReducer

Complex Logic: Ideal when state has multiple sub-values, nested objects, or when future state depends on previous state.
Separation of Concerns: Improves testability by separating logic from rendering.
Context Pairing: Useful with useContext for managing global state without external libraries. 

Note: Always return a new state object (immutability) in the reducer.
