useState is used for simple state management, returning the state value and a setter function. useReducer is better for complex state logic or when the next state depends on the previous one, using a reducer function and a dispatch method to handle actions. 


When to use which hook

Feature 	useState	useReducer

Complexity	Simple state (e.g., single boolean, number, or string).	Complex logic involving multiple sub-values, objects, or arrays.

Update Mechanism	A simple setter function is called directly with the new state value (e.g., setCount(count + 1)).	A dispatch function is called with an action object (e.g., { type: 'increment' }), and a separate reducer function determines the new state based on the action.

Logic Location	State transition logic is often within the component's event handlers.	State logic is centralized in a single, separate reducer function, which improves testability and organization.

Performance	Triggers re-renders with every update.	Can optimize performance for components with deep updates by passing the dispatch function down instead of callbacks.

useState Example: Simple Counter 

This example demonstrates a simple counter where the state is a single number, updated with a direct setter function. 
jsx
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <button onClick={() => setCount(count - 1)}>Decrement</button>
    </div>
  );
}
useReducer Example: Complex Counter
This example manages the same counter with useReducer. The logic for state updates is centralized in the reducer function, making it more suitable if the logic were to become more complex (e.g., adding a "reset" action). 

import React, { useReducer } from 'react';

// The reducer function defines how the state changes based on actions
function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    default:
      return state;
  }
}

const initialState = { count: 0 };

function ComplexCounter() {
  const [state, dispatch] = useReducer(reducer, initialState);

  return (
    <div>
      <p>Count: {state.count}</p>
      {/* Dispatch actions to update the state */}
      <button onClick={() => dispatch({ type: 'increment' })}>Increment</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>Decrement</button>
    </div>
  );
}
