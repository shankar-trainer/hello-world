To perform CRUD (Create, Read, Update, Delete) operations in React using Axios, you can use the following examples within functional components, typically utilizing useState for state management and useEffect for data fetching. 

First, ensure you have Axios installed in your React project: 
bash
npm install axios
Here are examples for each operation, assuming an API endpoint like https://api.example.com/data: 

1. Read Data (GET)
This example uses useEffect to fetch data when the component mounts. 
javascript

import React, { useEffect, useState } from 'react';
import axios from 'axios';

const ReadComponent = () => {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // Make a GET request to retrieve all data
    axios.get('https://api.example.com/data')
      .then(response => {
        setData(response.data);
        setLoading(false);
      })
      .catch(error => {
        console.error('Error fetching data:', error);
        setLoading(false);
      });
  }, []); // The empty dependency array ensures this runs once when the component mounts

  if (loading) return <p>Loading data...</p>;

  return (
    <div>
      <h2>Data List</h2>
      <ul>
        {data.map(item => (
          <li key={item.id}>{item.name}</li>
        ))}
      </ul>
    </div>
  );
};

export default ReadComponent;
2. Create Data (POST)
This example uses a form to add new data to the API. 
import React, { useState } from 'react';
import axios from 'axios';

const CreateComponent = ({ setData, data }) => {
  const [newData, setNewData] = useState({ name: '' });

  const handleInputChange = (event) => {
    setNewData({ ...newData, [event.target.name]: event.target.value });
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    // Make a POST request to add new data
    axios.post('https://api.example.com/data', newData)
      .then(response => {
        setData([...data, response.data]); // Update the local state with the new item
        setNewData({ name: '' }); // Clear the form input
      })
      .catch(error => {
        console.error('Error adding data:', error);
      });
  };

  return (
    <div>
      <h2>Add New Data</h2>
      <form onSubmit={handleSubmit}>
        <input
          type="text"
          name="name"
          value={newData.name}
          onChange={handleInputChange}
          placeholder="Enter name"
          required
        />
        <button type="submit">Add</button>
      </form>
    </div>
  );
};

// Note: This component would be used within a parent component that manages the main 'data' state.
export default CreateComponent;
3. Update Data (PUT or PATCH)
This example shows the logic for updating an existing item. This would typically be part of an edit form. 
import axios from 'axios';

const updateData = (id, updatedItem, data, setData, setSelectedData) => {
  // Make a PUT request to update the specific item
  axios.put(`https://api.example.com/data/${id}`, updatedItem)
    .then(response => {
      // Update the local state by replacing the old item with the updated one
      const updatedData = data.map(item => {
        if (item.id === id) {
          return response.data;
        }
        return item;
      });
      setData(updatedData);
      setSelectedData(null); // Close the edit form
    })
    .catch(error => {
      console.error('Error updating data:', error);
    });
};

// This function is the core logic. It is typically integrated into a component with an edit form and state for the selected item (see source).
4. Delete Data (DELETE)
This example provides the function to remove an item by its ID. 
javascript
import axios from 'axios';

const deleteData = (id, data, setData) => {
  // Make a DELETE request to remove the item with the given ID
  axios.delete(`https://api.example.com/data/${id}`)
    .then(() => {
      // Update the local state by filtering out the deleted item
      const updatedData = data.filter(item => item.id !== id);
      setData(updatedData);
    })
    .catch(error => {
      console.error('Error deleting data:', error);
    });
};

// This function can be called from a button within a list item (e.g., <button onClick={() => deleteData(item.id, data, setData)}>Delete</button>).
