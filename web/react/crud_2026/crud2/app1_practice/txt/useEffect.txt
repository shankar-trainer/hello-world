The useEffect Hook in React allows you to perform side effects in functional components, such as data fetching, subscriptions, or manual DOM updates. It serves a combined purpose similar to the componentDidMount, componentDidUpdate, and componentWillUnmount lifecycle methods in class components. 

Syntax
The useEffect hook accepts two arguments:
useEffect(setup, dependencies?) 

setup: A function containing the side effect logic. This function can optionally return another function for cleanup.
dependencies (optional): An array of values (props, state, etc.) that the effect depends on. The effect re-runs only when one of these values changes. 

Usage Scenarios and the Dependency Array 
The second argument, the dependency array, controls when the effect runs. 

Runs after every render (default behavior): If you omit the dependency array, the effect runs after every single render of the component.
jsx
useEffect(() => {
  // Runs after every render
});
Runs only once on mount: Passing an empty array ([]) tells React that your effect doesn't depend on any values that change, so it runs only once after the initial render. This is ideal for initial data fetching.
jsx
useEffect(() => {
  // Runs only once (on mount)
  fetchData();
}, []);
Runs when specific values change: Including specific props or state variables in the array will cause the effect to re-run only when any of those dependencies change.
jsx
useEffect(() => {
  // Runs on mount and whenever 'count' or 'userId' changes
  fetchData(count, userId);
}, [count, userId]);


=================
import React, { useState, useEffect } from 'react';

function UseEffect1() {
  const [count, setCount] = useState(0);

  // Runs after the initial render and every time 'count' changes
  useEffect(() => {
    document.title = `You clicked ${count} times`;
  }, [count]); // Dependency array includes 'count'

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
export default UseEffect1;
