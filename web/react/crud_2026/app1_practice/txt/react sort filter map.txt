phone.js props pass as array with sort filter example

To pass an array as a prop and then sort and filter it within a React component, you perform the filtering and sorting operations in the render method or 
a useMemo hook (for functional components) before rendering the list. This ensures the original prop data remains immutable. 

Below is an example using a functional component with useState for filter/sort criteria and applying the logic in the render phase. 
Example Implementation
1. Parent Component (App.js)
This component holds the original data and passes it as a prop to the child component. 
jsx
import React from 'react';
import ItemList from './ItemList';

const App = () => {
  const phoneData = [
    { id: 1, name: 'Samsung S21', price: 999, brand: 'Samsung' },
    { id: 2, name: 'iPhone 13 Pro', price: 1099, brand: 'Apple' },
    { id: 3, name: 'Samsung A52', price: 499, brand: 'Samsung' },
    { id: 4, name: 'Google Pixel 6', price: 799, brand: 'Google' },
    { id: 5, name: 'iPhone SE', price: 399, brand: 'Apple' },
  ];

  return (
    <div>
      <h1>Phone List App</h1>
      {/* Pass the array as a prop named 'items' */}
      <ItemList items={phoneData} />
    </div>
  );
};

export default App;
2. Child Component (ItemList.js)
This component receives the array as a prop and applies the sort and filter logic dynamically based on user input. 
jsx
import React, { useState, useMemo } from 'react';

const ItemList = ({ items }) => {
  const [filterBrand, setFilterBrand] = useState('');
  const [sortOrder, setSortOrder] = useState('asc'); // 'asc' or 'desc'

  // Filter the items
  const filteredItems = useMemo(() => {
    return items.filter(item => {
      // If no filter is set or the brand matches the filter, keep the item
      return filterBrand === '' || item.brand === filterBrand;
    });
  }, [items, filterBrand]); // Re-run when items or filterBrand changes

  // Sort the filtered items (non-destructively using slice() to copy the array first)
  const sortedAndFilteredItems = useMemo(() => {
    // Use slice() to create a copy and avoid mutating the original prop
    return filteredItems.slice().sort((a, b) => {
      if (sortOrder === 'asc') {
        // Sort by price ascending
        return a.price - b.price;
      } else {
        // Sort by price descending
        return b.price - a.price;
      }
    });
  }, [filteredItems, sortOrder]); // Re-run when filteredItems or sortOrder changes

  return (
    <div>
      {/* Controls for Filtering */}
      <div>
        <label>Filter by Brand: </label>
        <select value={filterBrand} onChange={(e) => setFilterBrand(e.target.value)}>
          <option value="">All</option>
          <option value="Samsung">Samsung</option>
          <option value="Apple">Apple</option>
          <option value="Google">Google</option>
        </select>
      </div>

      {/* Controls for Sorting */}
      <div>
        <label>Sort by Price: </label>
        <select value={sortOrder} onChange={(e) => setSortOrder(e.target.value)}>
          <option value="asc">Low to High</option>
          <option value="desc">High to Low</option>
        </select>
      </div>

      {/* Display the results */}
      <ul>
        {sortedAndFilteredItems.map(item => (
          <li key={item.id}>
            {item.name} - {item.brand} - ${item.price}
          </li>
        ))}
      </ul>
    </div>
  );
};

export default ItemList;

Key Concepts
Passing Props: The phoneData array is passed to the ItemList component via the items prop using standard JSX syntax.

Immutability: The original items prop is never directly modified. Instead, JavaScript array methods like .filter() and .sort() (combined with .slice()) are used to create new arrays based on the original data.

useMemo Hook: useMemo is used to cache the filtered and sorted arrays. This improves performance by only recalculating the lists when the items prop, filterBrand, or sortOrder state variables change.

Dynamic Rendering: The component re-renders automatically when the filterBrand or sortOrder state is updated, displaying the new filtered and sorted list.
