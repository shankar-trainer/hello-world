Hashing is a powerful technique used in data structures to store and retrieve data efficiently, ideally achieving constant time complexity  for search, insertion, and deletion. It works by transforming a large key (like a name or ID) into a smaller integer value, which serves as an index in an array known as a Hash Table. [1, 2, 3, 4]  
How Hashing Works 

1. Key: The unique input data (e.g., a student ID) you want to store. 
2. Hash Function: A mathematical algorithm that processes the key and returns a "hash code" or index. 
3. Hash Table: An array-like structure where data is actually stored at the index calculated by the hash function. [1, 4, 5, 6, 7]  

Common Hash Functions 

• Division Method: Computes the index using the modulo operator: $h(k) = k \mod m$, where $m$ is the table size (often a prime number). 
• Multiplication Method: Multiplies the key by a constant $A$ (between 0 and 1), extracts the fractional part, and multiplies it by the table size. 
• Mid-Square Method: Squares the key and extracts the middle digits to form the index. [1, 5, 8, 9, 10]  

The Challenge: Collisions 
A collision occurs when two different keys result in the same hash index. Since two items cannot occupy the same slot, developers use collision resolution techniques: 

• Chaining (Closed Addressing): Each slot in the hash table points to a linked list of all elements that hash to that same index. 
• Open Addressing: If a collision occurs, the algorithm searches for the next available slot in the table using methods like: 

	• Linear Probing: Checking the very next slot ($i+1$). 
	• Quadratic Probing: Checking slots at intervals of $i^2$. 
	• Double Hashing: Using a second hash function to find the next slot. [8, 12, 15, 16, 17]  

Real-World Applications 

• Associative Arrays: Implementing dictionaries (Python) or maps (C++, Java). 
• Database Indexing: Speeding up data retrieval in large databases. 
• Cryptography: Using secure algorithms like SHA-256 for password storage and data integrity. 
• Caches: Quickly looking up frequently accessed web data. [1, 5, 18, 19, 20, 21]

**Hashing** is a fundamental technique in data structures used to uniquely identify an object and store it in a way that allows for **lightning-fast retrieval**.

Instead of searching through an entire collection element by element—which takes $O(n)$ time—hashing allows you to find, insert, or delete data in **$O(1)$ constant time** on average.

---

## How Hashing Works (The Big Picture)

Think of hashing like a library. Instead of pile-searching every book, a formula takes the book's title and tells you the exact aisle and shelf it belongs to.

1. **Key:** The input data you want to store or look up (e.g., a student's name or ID).
2. **Hash Function:** An algorithm that takes the key and converts it into a fixed-size integer (the **hash code**).
3. **Bucket/Index:** The hash code is typically mapped (using a modulo operation) to a specific index in an array (the **Hash Table**).

---

## The Catch: Collision Handling

Sometimes, two completely different keys will produce the exact same array index. This is called a **Collision**. Since two items can't sit in the exact same slot, Java handles this in a couple of ways:

* **Separate Chaining (Used by Java's `HashMap`):** Each slot in the array points to a linked list (or a balanced tree). If a collision occurs, the new item is just added to the list at that index.
* **Open Addressing:** If a slot is taken, the algorithm looks for the next available slot based on a specific probing sequence.

---

## Hashing in Java

Java makes hashing incredibly easy by building it right into the language. Every object in Java inherits two crucial methods from the `Object` class:

* `public int hashCode()`: Returns an integer value generated by a hashing algorithm.
* `public boolean equals(Object obj)`: Checks if two objects are actually equal, which is vital for resolving collisions.

### Common Hashing Collections in Java:

* **`HashMap<K, V>`:** Stores data in Key-Value pairs.
* **`HashSet<E>`:** Stores unique elements only (built on top of a `HashMap`).

## Complete Java Example: Using `HashMap`

Here is a practical example demonstrating how Java uses hashing to store and retrieve student grades instantly.

```java
import java.util.HashMap;

public class HashingExample {
    public static void main(String[] args) {
        // 1. Create a HashMap (Key: String/Student Name, Value: Integer/Grade)
        HashMap<String, Integer> studentGrades = new HashMap<>();

        // 2. Insert Data (Hashing happens under the hood)
        // Java calculates hashCode("Alice"), maps it to an index, and stores the pair.
        studentGrades.put("Alice", 95);
        studentGrades.put("Bob", 88);
        studentGrades.put("Charlie", 92);

        // 3. Retrieve Data in O(1) Time
        // Java hashes "Bob", goes straight to his index, and pulls the value.
        String searchKey = "Bob";
        if (studentGrades.containsKey(searchKey)) {
            int grade = studentGrades.get(searchKey);
            System.out.println(searchKey + "'s Grade: " + grade);
        } else {
            System.out.println(searchKey + " not found.");
        }

        // 4. Remove an item
        studentGrades.remove("Charlie");

        // Print the entire map
        System.out.println("Updated Student Records: " + studentGrades);
    }
}

```

### Output:

```text
Bob's Grade: 88
Updated Student Records: {Alice=95, Bob=88}

```
