A Stack is a linear data structure in Java that follows the Last-In, First-Out (LIFO) principle, meaning the last element added is the first one to be removed. 

In Java, you can use the built-in Stack Class from the java.util package for standard tasks, or implement one manually using an array or linked list for more control.

1. Manual Implementation (Using Arrays)Implementing a stack manually involves managing an internal array and a top variable that tracks the index of the latest element.

Stack {
    private int maxSize;
    private int[] stackArray;
    private int top;

    public ManualStack(int size) {
        this.maxSize = size;
        this.stackArray = new int[maxSize];
        this.top = -1; // Indicates an empty stack
    }

    // Add element to top
    public void push(int value) {
        if (top == maxSize - 1) {
            System.out.println("Stack Overflow");
            return;
        }
        stackArray[++top] = value;
    }

    // Remove and return top element
    public int pop() {
        if (top == -1) {
            System.out.println("Stack Underflow");
            return -1;
        }
        return stackArray[top--];
    }

    // View top element without removing
    public int peek() {
        if (top == -1) return -1;
        return stackArray[top];
    }

    public boolean isEmpty() {
        return (top == -1);
    }
}
Use code with caution.2. Core OperationsEvery stack implementation must support these primary methods:push(): Adds an item to the top of the stack.pop(): Removes and returns the item from the top.peek(): Returns the top item without removing it.empty() or isEmpty(): Checks if the stack contains any elements.3. Built-in Stack ExampleFor most applications, use the Java Stack documentation to implement the ready-to-use version from the Collections framework.javaimport java.util.Stack;

public class Main {
    public static void main(String[] args) {
        Stack<String> stack = new Stack<>();

        // Adding elements
        stack.push("First");
        stack.push("Second");
        stack.push("Third");

        // View top element (Third)
        System.out.println("Top: " + stack.peek());

        // Removing elements
        System.out.println("Popped: " + stack.pop()); // Removes "Third"
        
        // Checking state
        System.out.println("Is empty? " + stack.empty());
    }
}
Use code with caution.4. Performance & ApplicationsTime Complexity: Push, Pop, and Peek operations are all \(O(1)\), as they only occur at one end of the structure.Use Cases: Stacks are used in Undo/Redo mechanisms, Browser history (back button), and managing Function calls in memory.
